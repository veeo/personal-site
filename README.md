# personal-site

Personal site for VeeO. This repo is the homepage: a portrait, a short introduction, and a journey of roles. It follows the Home frame in the site’s Figma file.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on all interfaces at [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Stack

Next.js, TypeScript, Tailwind CSS, and shadcn/ui.
